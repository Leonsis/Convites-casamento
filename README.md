# Convites Casamento

Projeto com modelos de convites de casamento em HTML, organizados em três exemplos distintos.

## Estrutura do projeto

- `convite1/` - Modelo de convite 1
- `convite2/` - Modelo de convite 2
- `convite3/` - Modelo de convite 3
- `fluxo-de-trabalho-do-projeto.md` - Documento com o fluxo de trabalho e informações do projeto

## Descrição

Cada pasta contém o arquivo `index.html` e seus recursos necessários para exibir um convite de casamento na web. O projeto serve como base para demonstração, testes e personalização de convites.

## Como usar

1. Abra a pasta de um convite, por exemplo `convite1/`.
2. Abra o arquivo `index.html` no navegador.

## Observações

- O projeto foi organizado para facilitar a comparação entre diferentes estilos de convite.
- Personalize os arquivos HTML e CSS conforme necessário para adaptar ao evento.
